## Misstep log (things that went wrong and were corrected)

1. **Tried `ALTER FUNCTION ... SET app.writer`** in migration 0031 as a
   function-level default for the derivation writer flag. This requires
   superuser and broke `supabase start` in CI. Removed in `2c625e0`; the
   test was fixed to clear the flag itself instead. The flag is a guard
   against accidental writes, not a security boundary — no security impact.

2. **Wrong fake pool in unit tests** — after adding the existing-verdict
   lookup in `_verdict_for_brief`, the fake `fetchone` only returned one
   row, causing IndexErrors in two tests. Fixed by extending the
   `side_effect` list.

3. **Ruff import order and line-length** in `m05_verdict.py` and `worker/app.py`
   — fixed with `ruff --fix` and string split.

## Key architectural constraints to remember

- **Write discipline (S8):** all writes go through `app.*` SECURITY DEFINER
  RPCs (`SET search_path = ''`, REVOKE from public/anon/authenticated, GRANT).
  `public.*` wrappers with role checks for the UI.
- **Derivation writer flag:** `SET LOCAL app.writer = 'derivation'` must be
  set transaction-locally before derivation writes. It is a guard, not a
  security boundary — it stays on for the rest of the transaction by design.
  Do NOT try to set it at the function level (needs superuser).
- **Roles:** Viewer < Operator < Editor < Admin < Owner. Verdict/identity
  review need Editor; replies/meetings need Operator.
- **int → smallint:** Postgres does not resolve `100` as `smallint` in
  function calls. Always cast explicitly: `100::smallint`.
- **PGlite superuser gap:** PGlite runs as superuser, real Supabase CI does
  not. PGlite passing does not guarantee CI passing for permission-sensitive
  SQL.
- **Next.js server components:** cannot import `'use client'` modules (e.g.
  `inputClass` from form helpers). Define styles locally or in a shared
  server-safe file.
- **LOCK.json:** whenever a prompt file changes, regenerate with
  `node scripts/generate-lock.mjs` (or `pnpm db:check` which calls it).
