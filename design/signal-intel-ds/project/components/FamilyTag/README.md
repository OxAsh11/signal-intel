# FamilyTag

Names the kind of component in words, in its family's tinted colours: shade 02 background, shade 09 text, 6px radius, 4px 12px padding, regular weight, with a small dot.

- **Provide:** `family` and `children` (the words: "Judgement", "Needs you · 4", "Discovery · funnel").
- Put one at the top of every family card, so colour is never the only signal.
- The guidelines put shade 06 text on shade 02 tags. That fails contrast for pool, mint and grass, so tags use shade 09, the tinted-mode headline rule.
