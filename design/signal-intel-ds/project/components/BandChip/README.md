# BandChip

Shows the priority band of an account under a Brief version: High, Medium, Low or Excluded.

- **Provide:** `band`; for Excluded, `reason` names the gate ("Competitor", "Exclusion list", "Contradicted").
- The pip meter encodes order (three, two, one, none), so bands read correctly without colour.
- Only High uses the solid `signal` fill. Keep it rare on screen: a table where every row is solid has lost its ranking.
