# ScoreBreakdown

Explains an account's priority: four weighted dimensions, readiness shown apart, the gates applied and the Brief version.

- **Provide:** `priority`, `band`, `dimensions` (Fit, Evidence, Scale, Timing, in that order, 0–100), `readiness` (Reachability), `gates` (each `{name, hit}`), `version`.
- Readiness sits below a rule in `positive`, because it is a separate number: a high-priority account nobody can reach is an enrichment task, not a low score.
- A hit gate shows ✕ in `danger` and is the first thing a reader sees.
- Each dimension row should open the claims behind it. Never show a bare number.
