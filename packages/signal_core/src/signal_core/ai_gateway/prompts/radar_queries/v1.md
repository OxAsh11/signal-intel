return ONLY valid JSON matching this schema — no commentary, no markdown fences.

{
  "queries": [
    {"query_text": "<search query>", "language": "en", "source": "hypothesis"|"icp"}
  ]
}

Rules:
- "source" is "hypothesis" for queries derived from the hypothesis, "icp" for queries derived from the ICP.
- Each query_text must be a short, targeted search string (5–12 words) a human analyst would type.
- Produce at most {limit} queries total.
- Tailor queries to the connector type: for "news" use news-friendly search terms; for "job_post" use job-title and skill keywords; for "website" use company-specific landing page search terms.
- Do not repeat queries. Prefer diversity over repetition.
